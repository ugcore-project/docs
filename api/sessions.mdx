A session is a routing bucket owned by ug-core: an instance for an apartment, a race or a heist. Buckets are allocated from 1000 up, so they never clash with buckets other resources use below that. Bucket 0 is the shared world. A player is in at most one session.

<Warning>Do not move players between buckets with `SetPlayerRoutingBucket` while they are in a session. Use `Join` and `Leave`.</Warning>

## Create

```lua
UgCore.Sessions.Create(options?) -> ok, sessionId, errorCode
```

<ResponseField name="name" type="string">Up to 64 characters.</ResponseField>
<ResponseField name="lockdown" type="'strict' | 'relaxed' | 'inactive'" default="strict">Client entity creation in the bucket.</ResponseField>
<ResponseField name="population" type="boolean" default="false">Ambient peds and vehicles.</ResponseField>
<ResponseField name="persistent" type="boolean" default="false">Keeps the session when the last member leaves.</ResponseField>

## Destroy

```lua
UgCore.Sessions.Destroy(sessionId) -> ok, errorCode
```

Moves every member back to the shared world.

## Join / Leave

```lua
UgCore.Sessions.Join(source, sessionId) -> ok, errorCode
UgCore.Sessions.Leave(source) -> ok, errorCode
```

`Join` leaves the current session first. `Leave` moves the player back to the shared world. An empty session that is not persistent is destroyed. Players also leave when they drop, and every session is destroyed when ug-core stops.

## Errors

| Function | Code | When |
| --- | --- | --- |
| `Destroy`, `Join` | `not_found` | The session does not exist. |
| `Join` | `not_loaded` | The player is not connected. |
| `Join` | `no_permission` | `Sessions:BeforeJoin` cancelled. |
| `Leave` | `not_found` | The player is in no session. |

Invalid options raise.

## Hooks

| Hook | Payload |
| --- | --- |
| `Sessions:BeforeJoin` | `{ source, sessionId }` |

It allows or cancels. Changes to the payload are ignored.

## Statebags

| Key | Value |
| --- | --- |
| `ug-core:Session` | Session id, or `nil` in the shared world |

## Example

```lua
local ok, sessionId = UgCore.Sessions.Create({ name = 'apartment:' .. characterId })

if ok then
    UgCore.Sessions.Join(source, sessionId)
end
```
