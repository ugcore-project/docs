Register with [`UgCore.Hooks.Register`](/api/hooks). Every name below is `UgCore.Enums.Hooks.<Group>.<Key>`: use the enum, never the string. Return `false` to cancel. The cancelled function returns `UgCore.Enums.Errors.NoPermission`.

```lua
-- Accounts:BeforeRemove
UgCore.Hooks.Register(UgCore.Enums.Hooks.Accounts.BeforeRemove, function(payload) end)
```

| Hook | Payload | Reads changes |
| --- | --- | --- |
| `Players:BeforeDown` | `{ source, cause }` | No |
| `Players:BeforeBleedout` | `{ source }` | No |
| `Players:BeforeRespawn` | `{ source, coords }` | No |
| `Players:BeforeRevive` | `{ source, by, reason, health, clearInjuries }` | No |
| `Guard:BeforeAction` | `{ source, action, score, flags }` | `action`, downgrade only |
| `Characters:BeforeCreate` | `{ source, name, data }` | `name`, `data` |
| `Characters:BeforeDelete` | `{ source, characterId }` | No |
| `Accounts:BeforeAdd` | `{ source, account, amount, reason }` | No |
| `Accounts:BeforeRemove` | `{ source, account, amount, reason }` | No |
| `Accounts:BeforeTransfer` | `{ source, targetCharacterId, account, amount, reason }` | No |
| `Jobs:BeforeSet` | `{ source, name, grade }` | No |
| `Gangs:BeforeSet` | `{ source, name, grade }` | No |
| `Sessions:BeforeJoin` | `{ source, sessionId }` | No |
| `Permissions:BeforeGroupAdd` | `{ identifier, group, by }` | No |
| `Permissions:BeforeGroupRemove` | `{ identifier, group }` | No |
| `Items:BeforeUse` | `{ source, name, slot, metadata }` | No |
| `Inventory:BeforeAdd` | `{ inventory, name, count, metadata, reason }` | No |
| `Inventory:BeforeRemove` | `{ inventory, name, count, metadata, reason }` | No |
| `Inventory:BeforeMove` | `{ from, fromSlot, to, toSlot, count, reason }` | No |
| `Inventory:BeforeOpen` | `{ source, inventory }` | No |
| `Inventory:BeforeClearOnRespawn` | `{ source }` | No |
| `Weapons:BeforeEquip` | `{ source, name, serial }` | No |
| `Shops:BeforePurchase` | `{ source, shop, item, count, price, total, account }` | `total`, lower only |

"Reads changes" lists the fields ug-core reads back from a returned table. Other hooks only allow or cancel.

## Notes

- `Players:BeforeBleedout` cancelled means the bleedout retries later. Use it to keep a player downed during CPR.
- `Guard:BeforeAction` `action` is a `UgCore.Enums.GuardActions` value: `Warn`, `Kick` or `Ban`. A hook MAY lower it, such as `Ban` to `Kick`, never raise it. `flags` are the recent flags, oldest first.
- `Characters:BeforeCreate` MAY fill `data`, for example a starting phone number.

```lua
UgCore.Hooks.Register(UgCore.Enums.Hooks.Guard.BeforeAction, function(payload)
    if payload.action == UgCore.Enums.GuardActions.Ban then
        payload.action = UgCore.Enums.GuardActions.Kick
        return payload
    end
end)
```
