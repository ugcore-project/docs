## Register

```lua
UgCore.Commands.Register(name, options, handler)
```

<ResponseField name="name" type="string" required>Starts with a lowercase letter, then letters, digits and underscores, up to 32 characters. Registers `/name`.</ResponseField>
<ResponseField name="options" type="UgCommandOptions" required>
  <Expandable title="fields" defaultOpen>
    <ResponseField name="help" type="string" />
    <ResponseField name="args" type="UgCommandArgument[]">Parsed and typed before the handler runs.</ResponseField>
    <ResponseField name="permission" type="string">ACE the player MUST have.</ResponseField>
    <ResponseField name="rate" type="{ max, per }" default="{ max = 3, per = 2000 }">Per player.</ResponseField>
    <ResponseField name="requirePlayer" type="boolean">Requires a loaded player.</ResponseField>
    <ResponseField name="console" type="boolean" default="true">Allowed from the server console.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="handler" type="fun(source, args)" required>`args` is keyed by argument name. `source` is `0` for the console.</ResponseField>

Registering the same name twice raises.

### Argument types

| Type | Value |
| --- | --- |
| `string` | One word, up to `max` characters (default 64). |
| `text` | The rest of the line, up to `max` characters (default 256). MUST be last. |
| `integer` | A whole number. |
| `number` | Any finite number. |
| `boolean` | `true`, `false`, `1` or `0`. |
| `player` | The source of a connected player. |

Each argument has `name`, `type`, and optional `optional`, `max` and `help`. Optional arguments MUST be trailing.

### Checks

For players, in order: ug-core is ready, rate limit, `requirePlayer`, `permission`, arguments, handler. The console skips the first four checks. Console failures print the error code and the usage instead of emitting an event.

## GetAll

```lua
UgCore.Commands.GetAll() -> UgCommandInfo[]
```

Commands sorted by name, with `name`, `help`, `permission` and `args`. Use it for chat suggestions, filtered by permission per player.

## Errors

ug-core shows nothing to players. A failed command emits `ug-core:Commands:Failed` so a chat or notification resource can display it:

| Code | When |
| --- | --- |
| `not_loaded` | `requirePlayer` is set and the player is not loaded. |
| `no_permission` | The player lacks the `permission` ACE. |
| `invalid_args` | An argument is missing or invalid. `argIndex` says which one. |
| `internal_error` | The handler raised. The error is logged on the server. |

Rate limited commands are dropped silently.

## Events

| Event | Arguments |
| --- | --- |
| `ug-core:Commands:Failed` | `(source, name, errorCode, argIndex)` |

```lua
UgCore.Events.On(UgCore.Enums.Events.Commands.Failed, function(source, name, errorCode, argIndex)
    -- show a message with your own notification resource
end)
```

## Example

```lua
UgCore.Commands.Register('givecash', {
    help = 'Give cash to a player',
    permission = 'ug.admin',
    args = {
        { name = 'target', type = 'player', help = 'Player id' },
        { name = 'amount', type = 'integer', help = 'Amount' },
    },
}, function(source, args)
    UgCore.Accounts.Add(args.target, 'cash', args.amount, 'admin:givecash')
end)
```
