<Badge color="purple">Shared</Badge>

Compare against enums, never against raw strings. Your editor autocompletes them and flags typos, and a renamed value updates every user. ug-core follows the same rule: its repository check rejects error codes, event names, hook names and statebag keys spelled out outside the enum files.

```lua
if UgCore.Players.GetDeathState(source) == UgCore.Enums.DeathState.Downed then
    -- ...
end
```

## Module enums

Modules add their own enums and event and hook groups. In your resource, they appear once ug-core has replicated its enabled modules, so read them after `UgCore.Lifecycle.On(UgCore.Enums.Lifecycle.Ready, ...)`. Enums of disabled modules never exist.

The `players` module, always enabled, adds:

| Enum | Values |
| --- | --- |
| `Enums.DeathState` | `Alive`, `Downed`, `Dead` |
| `Enums.BodyRegion` | `Head`, `Neck`, `Torso`, `LeftArm`, `RightArm`, `LeftLeg`, `RightLeg`, `Unknown` |
| `Enums.DamageCategory` | `Gunshot`, `Stab`, `Blunt`, `Explosion`, `Fire`, `Fall`, `Vehicle`, `Drowning`, `Animal`, `Unknown` |
