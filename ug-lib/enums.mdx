## Events

Local events from ug-lib reach every resource on the client. Check `GetInvokingResource()` is `ug-lib` before trusting them.

| Event | Arguments |
| --- | --- |
| `Events.Cache.Changed` | `(key, value, oldValue)` |
| `Events.Ui.Opened` | `(type, ownerResource)`, when a modal opens |
| `Events.Ui.Closed` | `(type, ownerResource)`, when it closes |

Prefer [`UgLib.Cache.On`](/ug-lib/cache) to the raw cache event.
