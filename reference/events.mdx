Subscribe with [`UgCore.Events.On`](/api/events). Names live in `UgCore.Enums.Events.<Group>.<Key>`. Events are emitted on the server unless noted.

<Info>`ug-core:*` events from any resource other than ug-core are dropped by `On` and `Once`.</Info>

## Lifecycle

<Badge color="purple">Server and client</Badge>

| Event | Arguments |
| --- | --- |
| `ug-core:Lifecycle:Changed` | `(newState, oldState)` |
| `ug-core:Lifecycle:Ready` | `()` |
| `ug-core:Lifecycle:Stopping` | `()` |

## Players

| Event | Arguments |
| --- | --- |
| `ug-core:Players:Loaded` | `(source)` |
| `ug-core:Players:Injured` | `(source, injury)` |
| `ug-core:Players:Downed` | `(source, cause)` |
| `ug-core:Players:Died` | `(source, cause)` |
| `ug-core:Players:Revived` | `(source, by, reason)` |
| `ug-core:Players:Respawned` | `(source, coords)` |
| `ug-core:Players:DeathStateChanged` | `(source, newState, oldState, cause)` |
