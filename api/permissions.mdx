<Badge color="blue">Server</Badge> Proxied to ug-core. See [Permissions for owners](/owners/permissions).

<ModuleInfo name="permissions" required deps={["identity"]} server="Permissions" />

Permissions are FiveM ACEs. Grants are stored in the database and applied as `add_ace identifier.<id> <permission> allow`, so every ACE check agrees, including `IsPlayerAceAllowed` and the `permission` option of callbacks, net events and commands.

Permission names are letters, digits, dots, dashes and underscores, such as `my-garage.admin`.

## Has

```lua
UgCore.Permissions.Has(source, permission) -> boolean
```

Checks the ACE, including ACEs from `server.cfg`.

## Grant

```lua
UgCore.Permissions.Grant(target, permission, by?) -> ok, errorCode
```

**MUST run in a thread.** Applies the ACE right away.

<ResponseField name="target" type="integer | string" required>A source or an identifier.</ResponseField>
<ResponseField name="by" type="string">Who granted it. Up to 64 characters.</ResponseField>

## Revoke

```lua
UgCore.Permissions.Revoke(target, permission) -> ok, removed, errorCode
```

**MUST run in a thread.** `removed` is `false` when it was not granted. ACEs from `server.cfg` stay.

## GetAll

```lua
UgCore.Permissions.GetAll(target) -> string[]
```

Permissions granted with `Grant`, sorted. ACEs from `server.cfg` are not listed.

## Errors

| Function | Code | When |
| --- | --- | --- |
| `Grant`, `Revoke` | `not_found` | The source has no primary identifier, such as a player who already dropped. |
| `Grant`, `Revoke` | `internal_error` | The database failed. |

Malformed permission names and targets raise.

<Warning>Grants need `add_ace resource.ug-core command allow` in `server.cfg`. ug-core reports it at boot when it is missing.</Warning>

## Example

```lua
CreateThread(function()
    local ok, err = UgCore.Permissions.Grant(source, 'my-garage.admin', 'console')
end)

if UgCore.Permissions.Has(source, 'my-garage.admin') then
    -- ...
end
```
