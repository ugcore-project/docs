Balances belong to the loaded character. Every change writes a ledger row in the same transaction. Accounts are defined in `config/accounts.lua`:

```lua config/accounts.lua
return {
    accounts = {
        cash = { label = 'Cash', startingBalance = 500, allowNegative = false },
        bank = { label = 'Bank', startingBalance = 5000, allowNegative = false },
        crypto = { label = 'Crypto', startingBalance = 0, allowNegative = false },
    },
}
```

Read the account list with `UgCore.Config.Get('accounts', 'accounts')`, on the server or the client.

## Server

### GetBalance / GetAll

```lua
UgCore.Accounts.GetBalance(source, account) -> integer?
UgCore.Accounts.GetAll(source) -> table<string, integer>?
```

`nil` when no character is loaded.

### Add / Remove / Set

```lua
UgCore.Accounts.Add(source, account, amount, reason?) -> ok, balance, errorCode
UgCore.Accounts.Remove(source, account, amount, reason?) -> ok, balance, errorCode
UgCore.Accounts.Set(source, account, balance, reason?) -> ok, balance, errorCode
```

<ResponseField name="account" type="string" required>An account from `config/accounts.lua`. Unknown accounts raise.</ResponseField>
<ResponseField name="amount" type="integer" required>1 to 1,000,000,000,000.</ResponseField>
<ResponseField name="reason" type="string">Up to 128 characters. Stored in the ledger.</ResponseField>
<ResponseField name="balance" type="integer?">The new balance.</ResponseField>

`Set` records the difference in the ledger. It accepts negative balances only for accounts with `allowNegative`, and raises otherwise.

### Transfer

```lua
UgCore.Accounts.Transfer(source, targetCharacterId, account, amount, reason?) -> ok, balance, errorCode
```

Moves money to another character, online or offline, in one transaction. Both ledgers get a row that points to the other character. `balance` is the sender's.

### GetLedger

```lua
UgCore.Accounts.GetLedger(source, account, limit?) -> ok, entries, errorCode
```

<ResponseField name="limit" type="integer" default="25">1 to 100.</ResponseField>
<ResponseField name="entries" type="UgLedgerEntry[]">
  Newest first.
  <Expandable title="fields">
    <ResponseField name="amount" type="integer">Signed change.</ResponseField>
    <ResponseField name="balanceAfter" type="integer" />
    <ResponseField name="reason" type="string?" />
    <ResponseField name="relatedCharacterId" type="integer?">The other side of a transfer.</ResponseField>
    <ResponseField name="createdAt" type="integer">Unix seconds.</ResponseField>
  </Expandable>
</ResponseField>

## Client

```lua
UgCore.Accounts.GetBalance(account) -> integer?
UgCore.Accounts.GetAll() -> table<string, integer>
```

The local player's balances, sent by the server to that player only, on load and on every change. Other players' balances never reach a client.

## Errors

| Function | Code | When |
| --- | --- | --- |
| `Add`, `Remove`, `Set`, `Transfer`, `GetLedger` | `not_loaded` | No character is loaded. |
| `Add` | `no_permission` | `Accounts:BeforeAdd` cancelled. |
| `Remove` | `no_permission` | `Accounts:BeforeRemove` cancelled. |
| `Remove`, `Transfer` | `insufficient_funds` | The balance is too low and the account does not allow negative balances. |
| `Transfer` | `invalid_args` | The target is the sender's own character. |
| `Transfer` | `no_permission` | `Accounts:BeforeTransfer` cancelled. |
| `Transfer` | `not_found` | The target character does not exist. |
| Every mutating function | `internal_error` | The database failed. The balance is unchanged. |

Unknown accounts, out-of-range amounts and long reasons raise.

## Events

| Event | Arguments |
| --- | --- |
| `ug-core:Accounts:Changed` | `(source, account, balance, delta, reason)` |

Server only. It fires for every change of an online character, including both sides of a transfer.

## Hooks

| Hook | Payload |
| --- | --- |
| `Accounts:BeforeAdd` | `{ source, account, amount, reason }` |
| `Accounts:BeforeRemove` | `{ source, account, amount, reason }` |
| `Accounts:BeforeTransfer` | `{ source, targetCharacterId, account, amount, reason }` |

Hooks allow or cancel. Changes to the payload are ignored.

## Example

```lua
local ok, balance, err = UgCore.Accounts.Remove(source, 'cash', price, 'my-shop:water')

if not ok then
    return err -- 'insufficient_funds', 'not_loaded', ...
end
```
