## Register

```lua
UgCore.Commands.Register(name, options, handler)
```

<ResponseField name="name" type="string" required>Starts with a lowercase letter, then letters, digits and underscores, up to 32 characters. Registers `/name`.</ResponseField>
<ResponseField name="options" type="UgCommandOptions" required>
  <Expandable title="fields" defaultOpen>
    <ResponseField name="help" type="string" />
    <ResponseField name="args" type="UgCommandArgument[]">Parsed and typed before the handler runs.</ResponseField>
    <ResponseField name="permission" type="string">ACE the player MUST have.</ResponseField>
    <ResponseField name="groups" type="string[]">1 to 16 [groups](/owners/permissions#groups). The player MUST be in at least one of them.</ResponseField>
    <ResponseField name="rate" type="{ max, per }" default="{ max = 3, per = 2000 }">Per player.</ResponseField>
    <ResponseField name="requirePlayer" type="boolean">Requires a loaded player.</ResponseField>
    <ResponseField name="console" type="boolean" default="true">Allowed from the server console.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="handler" type="fun(source, args)" required>`args` is keyed by argument name. `source` is `0` for the console.</ResponseField>

Registering the same name twice raises.

### Who can use it

| Options | Allowed players |
| --- | --- |
| Neither | Everyone. |
| `permission` | Players with the ACE, from a group, a grant or `server.cfg`. |
| `groups` | Members of any listed group. Inheritance counts: with `groups = { 'admin' }`, a `founder` that inherits `admin` is allowed. |
| Both | Players who pass both. |

```lua
UgCore.Commands.Register('announce', {
    groups = { 'moderator', 'admin' },
    args = { { name = 'message', type = 'text' } },
}, function(source, args)
    -- ...
end)
```

<Tip>
  Prefer `permission` in resources you share: owners decide which groups get it in `config/permissions.lua`. Use `groups` for commands tied to your own server's staff ranks.
</Tip>

A group missing from `config/permissions.lua` logs a warning at registration and matches nobody. It does not raise, so renaming a group never breaks a resource.

### Argument types

| Type | Value |
| --- | --- |
| `string` | One word, up to `max` characters (default 64). |
| `text` | The rest of the line, up to `max` characters (default 256). MUST be last. |
| `integer` | A whole number. |
| `number` | Any finite number. |
| `boolean` | `true`, `false`, `1` or `0`. |
| `player` | The source of a connected player. |

Each argument has `name`, `type`, and optional `optional`, `max` and `help`. Optional arguments MUST be trailing.

### Checks

For players, in order: ug-core is ready, rate limit, `requirePlayer`, `permission` and `groups`, arguments, handler. The console skips the first four checks. Console failures print the error code and the usage instead of emitting an event.

## CanUse

```lua
UgCore.Commands.CanUse(source, name) -> boolean
```

True when the player passes the command's `permission` and `groups`. Use it to show only usable commands in chat suggestions and menus. Rate limits, `requirePlayer` and arguments are not checked. Unknown commands return `false`. Source `0` is the console.

## GetAll

```lua
UgCore.Commands.GetAll() -> UgCommandInfo[]
```

Commands sorted by name, with `name`, `help`, `permission`, `groups` and `args`.

```lua
local function suggestionsFor(source)
    local list = {}

    for _, command in ipairs(UgCore.Commands.GetAll()) do
        if UgCore.Commands.CanUse(source, command.name) then
            list[#list + 1] = command
        end
    end

    return list
end
```

## Errors

ug-core shows nothing to players. A failed command emits `ug-core:Commands:Failed` so a chat or notification resource can display it:

| Code | When |
| --- | --- |
| `not_loaded` | `requirePlayer` is set and the player is not loaded. |
| `no_permission` | The player lacks the `permission` ACE, or is in none of the `groups`. |
| `invalid_args` | An argument is missing or invalid. `argIndex` says which one. |
| `internal_error` | The handler raised. The error is logged on the server. |

Rate limited commands are dropped silently. Invalid options raise at registration.

## Events

| Event | Arguments |
| --- | --- |
| `ug-core:Commands:Failed` | `(source, name, errorCode, argIndex)` |

```lua
UgCore.Events.On(UgCore.Enums.Events.Commands.Failed, function(source, name, errorCode, argIndex)
    -- show a message with your own notification resource
end)
```

## Example

```lua
UgCore.Commands.Register('givecash', {
    help = 'Give cash to a player',
    groups = { 'admin' },
    args = {
        { name = 'target', type = 'player', help = 'Player id' },
        { name = 'amount', type = 'integer', help = 'Amount' },
    },
}, function(source, args)
    UgCore.Accounts.Add(args.target, 'cash', args.amount, 'admin:givecash')
end)
```

A moderation command that respects ranks:

```lua
UgCore.Commands.Register('kick', {
    groups = { 'moderator' },
    args = { { name = 'target', type = 'player' }, { name = 'reason', type = 'text', optional = true } },
}, function(source, args)
    if not UgCore.Permissions.CanTarget(source, args.target) then
        return
    end

    UgCore.Players.Kick(args.target, args.reason)
end)
```
